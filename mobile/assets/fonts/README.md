# Satoshi fonts

Source: [Fontshare Satoshi](https://www.fontshare.com/fonts/satoshi), downloaded 2026-10-10.
Use the unmodified Satoshi-Italic.otf and Satoshi-LightItalic.otf faces.
Run `npm run fonts:fetch --prefix mobile` from the repository root; start/build run it automatically.
The script validates SHA-256 hashes and fails if the upstream font files change.

Fontshare's distributed ITF Free Font License v2.0 permits embedding in the licensee's own
application but restricts redistribution of loose fonts. OTFs are Git-ignored; each build fetches
its own official copy. The fonts are then bundled for offline app use. Obtain the full current
terms from [Fontshare](https://www.fontshare.com/licenses) or the official download archive.
Do not modify, convert or subset the font files.
